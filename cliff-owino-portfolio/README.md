# Cliff Owino Portfolio

A responsive personal portfolio website for Cliff Owino built with HTML, CSS, and vanilla JavaScript.

## Project structure

- `index.html` — main content and SEO meta tags
- `css/style.css` — styling, layout, responsiveness, animations, and theme
- `js/script.js` — navigation behavior, scroll effects, typing animation, filters, and form validation
- `assets/images` — image assets and generated social share image
- `assets/icons` — icon assets if needed

## Run locally

From this folder, start a local web server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in a browser.
